# CFD2D
This project simulates a 2 dimensional shear layer, using periodic boundary conditions and FFT(W).
Originally developed for a Computational Physics course held in 2024, this code is able to simulate laminar and turbulent flows in 2 dimensions.

## Visualization
To visualize the outcome, use the provided gnuplot files, located in the corresponding folder.
